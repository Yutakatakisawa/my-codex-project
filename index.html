Features

HeroUIライクな体験を、さらに実装しやすく。

見た目のかっこよさだけでなく、開発者体験と拡張性を重視した設計です。

01

Polished Visual Language

グラデーション、グラスモーフィズム、滑らかなモーションで第一印象を最大化。

02

Composable Components

小さな部品を組み合わせて、プロダクトごとに最適なUIを構築できます。

03

First-Class Accessibility

キーボード操作、ARIA属性、コントラスト設計をデフォルトで備えます。

04

Theme Tokens

トークン駆動で色・角丸・間隔・影を一元管理し、ブランド適用を高速化します。

05

Performance Friendly

軽量構成を意識し、初期表示速度を落とさずリッチなUIを実現。

06

Developer Focused Docs

ユースケース中心のドキュメントとコピー可能なコードで導入を短縮します。
