# Wixワイヤー配置図（実装用）

このドキュメントは、`/shindan`（診断ページ）と`/shindan-result`（結果ページ）を  
**Wixエディタ上で迷わず配置するための設計図**です。

前提:
- すでに `WIX_SETUP_GUIDE.md` の要素IDとVeloコードを使う
- ここでは「どこに何を置くか」を固定する

---

## 3. Wixでの操作順（配置のみ）

1. 新規ページ `/shindan` を作成
2. セクションを3つ作る
   - ヒーロー
   - フォーム本体
   - 送信ボタンエリア
3. `#nameInput`, `#industryDropdown`, `#areaInput` を上部配置
4. `#q1`〜`#q20` を縦積みで配置
5. 最下部に `#errorText`（collapse）と `#submitBtn` を配置
6. 新規ページ `/shindan-result` を作成
7. 結果ヘッダー -> 解説 -> 3アクション -> LINE誘導の順で配置
8. IDが一致しているか確認

## 4. 余白・文字サイズの推奨値

### `/shindan`
- H1: 36px（SP 26px）
- 本文: 16px（SP 14px）
- 設問文: 20px（SP 18px）
- 選択肢: 16px（SP 15px）
- セクション余白: 48px（SP 28px）

### `/shindan-result`
- タイプ名: 34px（SP 24px）
- スコア: 24px（SP 20px）
- 本文: 16px（SP 15px）
- アクション: 18px（SP 16px）
- LINEボタン高さ: 52px（SP 48px）

## 5. 見た目最適化（推奨）

### 色
- 主色: `#1A365D`
- CTA: `#22C55E`（LINEボタン）
- 警告: `#DC2626`（エラー）
- 背景: `#F8FAFC`

### ボタン
- 角丸: 10px
- 太字: 700
- hover: 明度を5%下げる

### スマホ
- ボタンは幅100%
- 1画面に情報を詰め込みすぎない
- 診断ページは「1設問1カード」で視認性優先
