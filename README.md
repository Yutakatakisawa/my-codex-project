# Aurora UI Landing (HeroUI Inspired)

HeroUI のようなモダンでクールなトーンを意識した、1ページ構成のランディングサイトです。

## 実装内容

- グラデーション背景 / ガラス感のあるビジュアル
- ヒーローセクション + インタラクティブなデモウィンドウ
- ローカルSVG画像アセットによるビジュアルショーケース
- コンポーネントカタログ（カテゴリフィルタ）
- テーマプレイグラウンド（Hue / Radius / Dark-Light 切替）
- プライシングセクション
- スクロールプログレスバー
- モバイルメニュー
- Revealアニメーション

## 技術スタック

- HTML
- CSS
- Vanilla JavaScript

## ローカル起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 画像アセット

`assets/images/` にSVG画像を配置しています。
